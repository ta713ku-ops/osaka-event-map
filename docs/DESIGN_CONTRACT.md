# どこいこ大阪 — Premiumデザイン契約

## 目的

起動直後の大阪マップから、「今日どこ行く？」の答えを最小の操作で決められる、明快で現代的な発見体験にする。

## トークン

- 主色 `#3B82F6`、副色 `#8B5CF6`、開催中 `#16A34A`、警告 `#D97706`、危険 `#DC2626`
- 面 `#FFFFFF`、背景 `#F8FAFC`、本文 `#111827`、補助文字 `#64748B`、境界 `#E2E8F0`
- Inter相当のシステムsans-serif、サイズ12 / 14 / 16 / 18 / 24 / 30 / 36px
- 間隔 4 / 8 / 12 / 16 / 24 / 32px、角丸 8 / 12 / 18px、影は地図上の浮遊面に限定

## 操作契約

- 初期画面は地図。一覧や編集ホームを先に出さない
- 常時条件は「今日」「今夜」「明日」「今週末」。その他は「条件」へ収納
- ピンは44px以上の操作面とカテゴリ文字を持ち、開催中を色とリングの両方で示す
- ピン選択はページ遷移せずボトムシート。欠損項目は表示しない
- 主CTAは「ここに行く（Apple Maps）」。Google Mapsと公式サイトも用意
- PCは候補38% / 地図62%、モバイルは地図と下部候補レール

## 品質ゲート

- 390×844と1280×800で横overflowなし、Safe Area対応、操作面44px以上
- semantic HTML、キーボード、focus-visible、Escape、focus trap / 復帰、WCAG 2.2 AA目標
- loading / error / emptyでも地図と復帰導線を維持
- `prefers-reduced-motion: reduce`で不要なモーションを抑制
- typecheck、unit/integration tests、production build、公開URLの実画面確認をすべて通過

## 禁止

- 祭りどころのロゴ、固有文言、画像、配色、ピン形状をコピーしない
- 絵文字を最終アイコンにしない
- フィルターや細部UIで地図を覆い尽くさない
- 時刻不明のイベントを「今夜」へ推測表示しない
