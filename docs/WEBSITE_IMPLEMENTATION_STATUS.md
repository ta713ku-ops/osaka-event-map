## 実装内容

- ホームは初期画面で検索、イベント画像・名称・開催日を見せる。読み込み時も画像とカードの高さを確保し、画面のずれを修正。
- 一覧と保存は共通カード。カードリンクと保存ボタンを分離し、長い本文は2行、料金条件は詳細に案内する。
- 詳細は開催日・時間・休催日・会場・料金・予約を先に表示。長い料金の全文は開閉して読める。予約が不明な場合は「未確認」、受付終了は終了の案内にする。
- 検索条件は各条件の解除・全解除を提供し、0件時は回復導線を表示。最初の6件から12件ずつ増やし、取得した全件に到達できる。
- 保存は `routeId` と最小スナップショットを端末内に保持。終了／取得対象から消失した保存を勝手に削除しない。保存失敗は成功として扱わない。
- 地図は未確認座標を推定しない。地図可能数と未確認数をスマホにも表示。距離は大阪駅または選択起点からの直線距離であることを示す。
- 旧データの汎用公式URLによるID重複4グループを解消。所有する公開IDを保持し、別催し／別日程のURL衝突を修正。旧 `61173c5be6cbafb70690` は「園芸の日」のまま。
- 公式照合で「すみ博」全体の日程と住吉公園での開催日を区別し、住吉公園は10月17日10〜16時に修正。中之島美術館の月曜休館・例外開館日、ひらかたパークの催事別日程を保持する。
