# 01 イベント情報の強化

最終更新: 2026-09-17（Asia/Tokyo）

## 目的

公式情報だけを根拠に、「今日・今夜・今週末にどこへ行くか」をサイト内で判断できる情報量と鮮度を増やす。件数のみではなく、収集成功、主要会場の対応、項目別保有率、重複、古い情報の排除を品質指標とする。

## 外部ベンチマークの境界

WalkerPlusは掲載漏れ・カテゴリ・主要会場を発見する監査用ベンチマークに限る。本文、画像、日時、価格、人物評価などを収集・転載しない。候補を見つけた場合も、主催者、会場、自治体などの公式ページで検証を完了するまで `events.json` へ入れない。

## 公開品質ゲート

公開イベントは次の全項目を満たす。

- イベント名
- 有効な開始日と、開始日以降の終了日
- HTTP(S) の公式URL
- `sourceId`
- 有効な `lastCheckedAt`
- 会場名、住所、公式座標のいずれか

条件を満たさないレコードは公開せず、理由別件数を収集レポートに残す。取得できない価格、時刻、住所、画像、予約条件、タグは補完しない。

## 日時と開催状態

- `今夜` は公式の開始時刻と終了時刻の両方があり、当日18:00以降と重なる場合だけ対象にする。
- 不明時刻を `09:00` / `23:59` などで補完しない。
- 離散開催日と休催日は `schedule.dates` / `schedule.closedDates` に保持し、連続期間とみなさない。
- 中止、延期、完売、受付終了は、公式の根拠がある場合だけ保持する。

## 重複と更新

- 同名・同日でも会場または明示開始時刻が異なる場合は統合しない。
- 欠落値は他の公式ソースで補完できるが、異なる明示値を自動上書きしない。
- 統合後も全ての `provenance` と公開済み `routeId` を維持する。
- 取得失敗を0件成功に丸めず `error` / `stale` を保持する。前回成功データの再利用上限は14日とする。
