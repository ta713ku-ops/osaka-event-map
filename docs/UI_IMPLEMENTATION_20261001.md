# UI再評価書の実装結果

対象: ホーム・一覧・詳細・ナビゲーション。storytellingの生成り・墨色・朱色と、日本語明朝の見出しを継続した。イベント件数・収集先・情報品質はUI比較の加点対象にしていない。

## 実装

- ホームは公式の体験写真と短い誘いを入口に、検索→季節特集→今日→週末→場所→全件入口の順へ変更。画像のないイベントは一覧で扱う。
- ヘッダーのブランドを1行にし、モバイルはホーム・検索・地図・保存を常時表示。運営集計はフッターの「情報源・更新について」へ移動。
- 一覧は詳細条件を折りたたみ、選択中の条件を常に表示。写真・ポスター・縦画像・低解像度画像を区別し、欠損時は空箱を省く。料金を短くし、予約・重要条件は残す。
- 詳細は写真とタイトル、日程・会場・料金を先頭へ。縦画像は専用構図にし、参加条件全文、経路、保存、公式出典を維持。
- 検索状態、一覧表示、スクロール、戻る時のフォーカスを履歴に保持。停止・キーボード・スワイプ・画面外停止・非表示時停止・reduced-motionを維持。
- 主役画像の読込失敗時は別の有効な公式画像へ切り替える。すべて失敗した場合もイベントは検索できる。料金の「なし」は無料と推測しない。
