# 追加公式ソースの対応範囲

最終確認日: 2026-09-05（Asia/Tokyo）

`collectAdditionalEvents({ fetchText, now })` は、親の取得関数から渡された公開レスポンスだけを解析する。認証ページ、会員限定ページ、robots/アクセス制限を回避する取得は行わない。イベントの開催日・開催場所・料金・画像 URL は公式レスポンスに明記された値だけを採用し、座標はこのアダプターでは補完しない。

## 現在のアダプター

## 主要会場台帳と発見候補

`data/source-registry.json` は30の主要会場、15の収集ソース、8分野を登録する。台帳への登録は収集済みを意味しない。アダプターのない会場は `gap`、取得はできるが記録0件または確認が古い場合は `warning` として `public/data/coverage.json` に出力する。

ATC、万博記念公園、ひらかたパーク、大阪城公園の公式イベント入口から、イベントらしい個別リンクだけを候補として抽出する。候補は `events.json` と完全に分離し、通常の収集アダプターが公式URL・開催日・大阪会場を持つレコードを生成するまで掲載しない。探索件数は入口ごとに60リンクを安全上限とし、ナビゲーション、言語切替、一覧、施設案内を除外する。これは大阪全体の網羅率やSNS上の話題性を測定する仕組みではない。

親の 2026-09-04 実取得プローブでは、既存 7 ソースが応答し、ソース別の目安は大阪市 4、OSAKA-INFO 40、大阪市立美術館 5、大阪中之島美術館 7、フェスティバルホール 24、イオンモール大阪ドームシティ 17、阪急うめだ本店 31 件だった。追加した 3 店舗については、同日確認した公開 JSON の現在/予定レコードが大日 44、日根野 30、茨木 24 件（共通パーサー適用後）だった。合計はソース間の同一催事を含むため、画面表示件数とは一致しない。掲載内容と「現在/予定」の判定は日々変わるため、これは固定スナップショットではなく取得確認の記録である。

2026-09-05 の公式ページ実取得確認（`now=2026-09-05`）では、ソース定義は既存10件に自然史博物館と Zepp Namba を加えた12件になっている。自然史博物館トップの最新記事から、14221（9月12日）1件、14237（11月14日・15日）2件、14212（9月23日シンポジウム）1件の計4件を、日付と大阪府内会場の明記を確認して取得対象にできた。14232 のキャンペーン記事や過去のお知らせはイベント条件を満たさず除外した。Zepp Namba は9月掲載15カードのうち、9月2日の過去公演と9月4日の中止公演を除く13件が `now` 時点の取得対象で、実例として [Zepp de LIVE（9月5日）](https://www.zepp.co.jp/hall/namba/schedule/single/?rid=155454) は OPEN 11:00 / START 11:30、陰陽座（9月10日）は OPEN 17:00 / START 18:00 と公式表示を確認した。自然史博物館4件・Zepp Namba 13件という数は掲載更新と `now` に依存する確認時点の値であり、親の live collector が生成するスナップショットを代替しない。

追加2ソースの取得結果も既存と同じ `success` / `error` / `stale` 契約で、`sourceId`、`lastCheckedAt`、公式 URL と日付・会場・時刻の `evidence`、分類タグの根拠を保持する。取得不能または構造変更を成功0件に丸めず、親の収集レポートで状態を確定する。

各ソースのレポートは `success` / `error` / `stale` のいずれかで、`count` と `checkedAt` を必ず持つ。HTTP 失敗、JSON 破損、既知のマークアップを検出できないレスポンスを `success` の 0 件として扱わない。

## テスト fixtures と本番データの分離

小さなパーサーテスト用レスポンスは [`scripts/sources/fixtures/`](../scripts/sources/fixtures/) に置く。各 fixture は実際の公式ページ/API の構造を再現した短いテスト入力で、完全な取得 snapshot ではない。日付・タイトル・公式リンクは確認済みの公開記録を使っているが、fixture 自体を本番データとしてビルドへ取り込まない。

本番の取得結果・前回成功データは `data/sources/` のコレクター管理下に置く。既存の [BODIK `270008_event.csv`](../data/sources/270008_event.csv) は別契約のため変更していない。fixture を `--cached` の取得元や実運用キャッシュとして扱わないこと。

## 未対応・意図的に追加していない範囲

- 大阪府内すべての市町村のイベントページを横断するアダプター。自治体ごとに HTML、PDF、カレンダー形式が異なるため、公式構造を確認できた市のページだけを登録している。
- 大阪市立自然史博物館以外の博物館、美術館、科学館の全館網羅。自然史博物館もトップから辿れる数値付き記事に限定し、公式イベントカレンダー（別ドメイン・別形式）や個別ページ・PDFを横断しない。
- Zepp Namba とフェスティバルホール以外のホール、ライブハウス、出演者情報。Zepp Namba も現行公開スケジュールのみで、過去月、貸切・法人イベント、終了時刻、他会場を網羅しない。人物の知名度・来場予定は公式本文に明記されない限り分類しない。
- 自然史博物館の記事で会場が大阪府外または不明な館外観察会など。会場の明示がない記事へ館住所を継ぎ足さず、今回のソースから除外する。
- イオンモール堺北花田、堺鉄砲町、りんくう泉南、四條畷。公式店舗一覧には掲載されているが、今回確認した `www.aeon.jp/sc/*/event/index.json` 形式ではなく別ドメインのサイト構成だったため、共通 JSON アダプターへ推測追加していない。公式の公開イベント API/構造を確認できた時点で個別対応する。
- 百貨店は阪急うめだ本店のみ。近鉄・高島屋などは、公式の公開一覧と個別リンク構造を確認したうえで別アダプターにする。
- 公式情報にない緯度・経度、イベント専用会場の所在地、終了時刻、通常料金、無料・期間限定・有名人タグの補完。

対応範囲を広げる場合も、先に公式入口、利用可能な公開データ形式、開催日・詳細 URL の同時取得可否を確認し、取得不能なソースは空の成功エントリとして登録せず、この文書に理由を追記する。
