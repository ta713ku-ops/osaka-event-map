# どこいこ大阪 Editorial デザイン契約

## 意図

大阪のイベントを「検索する前に行きたくなる」編集型ホームから発見し、必要になった時だけ既存の地図・比較・経路案内へ進める。

## デザインシステム

- 基盤: Awesome Design Skills の `Editorial`
- 色: 墨 `#171311`、生成り `#F7F1E7`、紙 `#FFFDF8`、大阪の朱 `#B33A2F`、深緑 `#345044`
- 書体: 日本語本文はシステムゴシック、見出しは日本語明朝系を優先。数字・補助ラベルはゴシック
- グリッド: 8px基準。本文最大幅1200px。カードは4/8px角、過度なカプセル形状を避ける
- 画像: 実データ画像を優先。汎用画像は会場公式画像と誤認させない。地図はサービス固有の機能として明確に残す

## 画面構成

1. ヘッダー: ブランド、イベント、地図、プロフィール
2. ヒーロー: 大阪の今日を伝えるコピー、開催件数、主要CTA「近くのイベントを探す」
3. 注目イベント: 写真と要点、詳細CTA
4. 開催中: 横スクロールまたはカード列
5. 探し方: エリア・カテゴリ・時期
6. 近日開催/季節の特集
7. 地図への再CTAとデータ出典

## 操作と状態

- ホームを初期表示し、地図は明示的なCTAで開く
- 検索、今日/今夜/明日/今週末、条件絞り込みをホームでも利用可能にする
- イベント詳細、Apple/Google Maps、プロフィール、現在地、空/読込/失敗状態を維持する
- すべての主要操作は44px以上、`focus-visible`を表示、Escapeでダイアログを閉じる
- 390x844で横はみ出しなし。1280x800では編集グリッドを活用する
- `prefers-reduced-motion`では自動切替を停止する
- ファーストビューは写真・見出し・背景の短い連動演出を持たせる。操作を遮るスプラッシュは設けない
- 「今から選べる場所」の一覧構成と読みやすさは維持し、演出の主役にしない
- 動きを止める操作では写真・背景を含む継続アニメーションを停止する

## 禁止事項

- 祭りどころのロゴ、固有コピー、赤の配色、画像、カード形状をそのまま複製しない
- トップを再び全面地図にしない
- 画像だけでイベント内容を伝えない
- 存在しない時刻・料金・会場情報を推測しない

## 品質ゲート

- typecheck/test/build
- 収集・閲覧の任意件数上限なし。重複を統合し、全件へ段階的に到達できる
- 公式情報の出典・確認日時・取得状況を保持し、失敗を成功や新しい確認日時に置き換えない
- 座標未確認は捏造せず、一覧で閲覧できるが地図マーカーと所要時間判定には使わない
- 有名人来場・展覧会・親子・無料・期間限定の分類は公式文面の根拠を保持する
- 390x844/1280x800の上部とスクロール後を実画面確認
- 横はみ出しなし、主要操作44px以上、キーボードフォーカス可視
- ホーム→地図→詳細→外部経路の一連操作
- Loading/Error/Empty、reduced motion
- 時間差の実画面で演出を確認し、停止操作・フォーカス保持も検証する
- 秘密情報スキャン、GitHub Pages公開版確認
