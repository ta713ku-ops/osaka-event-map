- 対象は[公開中のどこいこ大阪](https://ta713ku-ops.github.io/osaka-event-map/)。未コミットのローカルUI変更は採点対象外。

- ブラウザで読み込み後の一覧、検索、共通詳細を確認。公開ホームの候補表示は495件だった。レコード数と、時刻・状態を反映した候補数を混同しない。
- 比較先の大阪全件一覧先頭10件、今週末一覧先頭10件、堺市一覧先頭10件、祭りどころ大阪一覧先頭12件を固定。名称表記の差は会場・公式URL・日程も照合した。

- 先頭ページの便宜サンプルであり、無作為抽出でも大阪全体の網羅率でもない。比較先の全件情報充足率・全件正確性は測定していない。

### 登録があっても週末に探せない例

「ある実験室からの脱出」は現在の公開レコードが10月2日のみ、「水上さんぽ 中之島公園ぐるっと」は10月1日のみ。比較先は広い会期で今週末一覧に載せているが、こちらの登録日は10月3～4日に重ならない。

こちらが公式カレンダーで確認できた日だけを載せる判断は、未確認日を推測するより慎重である。ただし1日分の予約枠を持つことと、会期全体・週末のお出かけを発見できることは同等ではない。優位性を判断するには、公式日程・予約枠の継続確認が必要。

## 公開検索で再現した情報の不整合

2026年10月1日21時台、22時前にブラウザで確認。

1. 検索語を「なんば雲海」にすると1件表示される。
2. 「これから」＋「無料」にすると0件になる。
3. 無料条件を外し、「今夜」にすると0件になる。
4. 直接詳細を開くと「無料」「17:30～22:00」「予約不要」が表示される。

公開JSONでは `price: 0` に対し `freeEvent: null`、無料タグなし。`timeInfo` に時刻はあるが `startTime`・`endTime`・毎日の開催を検索へ伝える構造化スケジュールがない。現在の絞り込みは無料フラグ／タグ、明示的時刻と開催日根拠を必要とするため、本文にある情報だけでは候補に入らない。夜間時間は[イベント公式](https://nambaparks.com/nambaunkai/)にも17:30～22:00とある。

時刻や毎日の開催を推測して通す修正はしない。公式根拠を保った構造化と無料条件の整合が必要。現状では、詳細の充実が「無料で今夜行ける催しを見つける」という利用者の目的へ届いていない。

## 比較先も正確性の基準そのものにはしない

祭りどころの大阪一覧は10月1日に「2026 ナイトZOO」を「本日開催」と表示したが、[動物園公式](https://www.tennojizoo.jp/event-info/46679/)の10月開催日は10日以降の指定日であり、1日ではない。こちらにこの催事がないことを掲載範囲の不足として数えても、比較先の当日表示まで正確とは認定しない。会期の広さと実際の開催日を分ける必要がある。

## 改善の優先順位と再判定条件

1. **取得済み情報と検索条件を一致させる。** なんば雲海の無料・夜間開催などを、明示的な公式根拠で構造化し、利用者の検索で発見できるようにする。
2. **固定サンプル外の漏れを公式で確認する。** 今回一次情報を確認した4件から着手し、堺・河内・泉州の催事へ対象を広げる。監査で見つけただけの催事は公式確認前に公開しない。
3. **会期と開催日・予約枠を別に保持する。** 1日分の予約確認で長期イベント全体をカバーしたと報告しない。休館日・離散開催日を今日／週末／今夜へ反映する。
4. **参加判断の不足を公式から取得する。** 時刻・料金の条件・予約・交通の欠落を優先。説明の長さだけを改善指標にしない。
5. **改修前に別の検証サンプルを固定する。** 今回の漏れを埋めた後も、未使用の地域・ジャンル・週末サンプル、共通詳細、公開検索で再評価する。

再判定では、掲載範囲、情報の厚さ、公式との整合、検索での発見性を別々に示す。「追加した固定対象をすべて載せた」ことだけで全体の優位としない。
