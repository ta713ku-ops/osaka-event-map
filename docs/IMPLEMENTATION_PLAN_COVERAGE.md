# 大阪イベント網羅性改善 実装計画

## 目標
- 固定収集先だけに依存せず、話題性の高い大阪イベントの見落としを検出する。
- 発見情報をそのまま公開せず、公式ページで日付・会場を確認できたイベントだけを掲載する。
- 「全件網羅」と誤認させず、対応カテゴリ・主要会場・最終確認・欠落候補を可視化する。
- 初期の必須回帰として「ジブリパーク展 大阪」を収集・検索可能にする。

## データ契約
- 公開eventは公式URL、公式文面にある開催日、府内会場を必須とする。検索やニュースは発見手段であり事実の根拠にはしない。
- discovery candidateは掲載eventと分離し、候補名・発見元・公式候補URL・検出時刻・照合状態を保持する。
- coverageはカテゴリ別/主要会場別の `tracked / healthy / warning / gap` と最終確認を保持する。件数を大阪全体の総数と表現しない。
- 失敗・HTML変更・未確認候補を成功扱いしない。前回データの利用期限は既存14日契約を維持する。

## Editorial UI契約
- 既存の墨・生成り・大阪の朱、明朝見出し、8pxリズム、4/8px角を維持する。
- 網羅状況は一覧やheroを邪魔しない通常フローの `<details>` または小さな編集カードにする。
- 「網羅」「すべて」など保証できない文言を使わず、「現在監視中」「未確認候補」を使う。
- 44px操作、focus-visible、読み込み/空/警告、390px横はみ出しなしを品質ゲートにする。
