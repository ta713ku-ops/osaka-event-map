# どこいこ大阪

「今日どこ行く？」に答える、大阪府のモバイルファースト・イベント発見アプリです。公式情報から集めた候補をホームで眺め、必要なときに地図・時間・距離・同行者・好みから絞り込めます。

## 起動

```bash
npm install
npm run dev
```

## iPhoneでローカル確認

MacとiPhoneを同じWi-Fiにつなぎ、Macで `npm run dev:lan` を実行します。
表示される `Network: http://192.168.x.x:5173/` をiPhoneのSafariで開いてください。
Macと開発サーバーを起動したまま使います。iPhone側の `localhost` はMacには接続しません。
ゲストWi-Fiの端末分離やmacOSのファイアウォールにより接続できない場合があります。
LANのHTTPでは現在地取得が制限されるため、大阪駅起点で確認してください。

起動直後はイベント発見ホームです。「今日」「今夜」「明日」「今週末」を切り替え、カードから詳細へ、地図から会場比較・外部経路案内へ進めます。ファーストビューの演出には停止操作があり、端末の視差効果を減らす設定にも対応します。

## データ更新

```bash
npm run collect
```

公式ソースを取得し、重複排除・型正規化して `public/data/events.json` を更新します。収集件数に固定上限は設けず、一覧は「もっと見る」で段階表示します。座標が未確認の情報は地図に推測のピンを置かず、一覧から公式情報を確認できるようにします。

ビルドではキャッシュを使います。取得失敗時に前回データを利用する場合も、確認日時は更新せず、取得状況を区別します。収集先ごとの対応範囲・制約は [収集範囲](docs/SOURCE_COVERAGE.md) を参照してください。大阪府内の全イベントを網羅するものではありません。
